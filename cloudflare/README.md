# 🚀 2026 Cloudflare Worker 极速 OpenAI / Claude 国内反代中枢

专为解决国内 NextChat、LobeChat、Cursor 及开发应用无法直连 `api.openai.com` 的痛点而设计。部署在 Cloudflare 全球边缘网络，毫秒级转发。

## ⚡ 1 秒极速部署方法

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)；
2. 进入 **Compute (Workers & Pages)** -> **Create Application** -> **Create Worker**；
3. 将 `worker.js` 代码直接粘贴进去，点击 **Deploy**；
4. 将你的自建应用 API Base URL 指向生成的 `*.workers.dev` 域名即可使用！
